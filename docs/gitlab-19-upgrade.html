19.3 到底新增了什么

能力 / 状态不要混淆的地方详细操作
Flow Creator：19.3 新增生成 YAML 后仍需注册、启用与配置触发器。创建可运行流程
冲突 / 讨论处理：19.3 GAGA 不代表实例已获授权或具备 Runner。冲突 / 讨论
MCP：19.3 仍为 Beta增强 MR 详情与列表等工具，不提供模型本身。认证与工具参数
CLI 插件：Experiment需 CLI ≥ 9.10.0，客户端与服务端分别核对。安装与复用
IDE 新 UI：Beta需 VS Code ≥ 6.88.1 / JetBrains ≥ 3.45.2；编码能力并非同时首次引入。补全、Chat 与 Flow
Session 任务计划 / Restricted / Credits caps组织管理能力，各有开关与使用边界。管理与验收
SAST 批量 AI 执行通常需要旗舰版与有效扫描结果。漏洞分诊与修复

Alfred 与非 AI 升级事项

Alfred workflow 已发布 v4.2.2，六个大版本的代表性源码检查支持继续使用 API v4；striding 实机联调仍待完成。查看完整矩阵与验证步骤。

19.3 的合并列车约束、默认分支密钥检测、CI 重试计数和作业标签等也值得核对；Secrets Manager 此次推出范围包含托管服务，不能直接算作 striding 自部署已具备。查阅极狐完整发布说明。
