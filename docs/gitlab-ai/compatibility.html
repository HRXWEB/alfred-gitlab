02 · v4.2.2 做了什么

  • 项目列表仍使用 GET /api/v4/projects、PRIVATE-TOKEN 和 membership 参数。
  • 增加 simple=true，保留搜索与克隆所需字段，减少无关项目配置传输。
  • Graph 从写死 main 改为 HEAD，适配不同默认分支名称。
  • 保留同一套多 host 缓存与导航逻辑，没有按 GitLab 大版本复制实现。

03 · 在 striding 上做最终验证

Alfred 命令 · 最后一条仅适用于实际名称为 striding 的 profile
glhostlist
glrefresh
gl <已知项目>
gl my striding

检查项目搜索、SSH / HTTP 克隆地址复制、个人页面和项目 Pipelines / Issues / MR / Members / Graph / CI/CD 设置入口。Graph 至少覆盖默认分支为 main 和 master 的项目。401 检查凭据有效期，403 检查访问策略；不因服务端升级就重复添加同一个 host。

04 · Alfred 不承担 AI 执行

Alfred 在这里负责快速打开项目和复制克隆地址。AI Agent 通过 IDE、CLI、MCP 或平台任务流接入，使用各自认证和权限。workflow 能导航到 19.3 的项目，不代表 Duo、MCP 或 Runner 已经配置。

上一篇管理 Agent 的执行、可见性、模型与用量继续资料索引与版本边界
